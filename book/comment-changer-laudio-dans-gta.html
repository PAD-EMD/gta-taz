Comment changer l'audio dans GTA?

08.10.2025
  • Anne-Sophie FOFANA
  • Romain NIVELLE
  • Sydney MAZÉ

30 septembre 2025, Eda TINMAZ, Rufaro MABUTO, Julika Hother, Julien CUISAT.

texte d'introduction: Ce tutoriel a pour but de présenter comment il est possible de modifier l'audio des assets dans GTA. À l'aide du logiciel Open IV, on peut accèder aux fichiers du jeu et les modifier. Ce tutoriel se concentre sur comment remplacer l'audio d'une arme.

1. Préparation

Outils à télécharger:
– OpenIV: openiv.com (gratuit)
(voir le tutoriel pour savoir comment installer OpenIV)
– Audacity: audacityteam.org (gratuit)

Préparez GTA V:
– Fermez complètement le jeu
– Fermez Steam/Epic Games Launcher
– Créez une sauvegarde (important!)

Préparez OpenIV:
– Exécuter en tant qu'administrateur
– Sélectionner "Grand Theft Auto V"
– Choisir "Windows" comme plateforme
– Créer un dossier "Mod" s'il n'existe pas encore

2. Sélection (des données à remplacer)

Naviguez jusqu'à l'audio que vous souhaitez remplacer:
C'est parfois difficile de trouver le bon, cliquez sur les différents fichiers audio, vous pouvez les reconnaître grâce au format ".awc"

– x64 > audio > sfx > WEAPONS_PLAYER.rpf > example: pistole (ptl_50cal.awc, …)


– Activer "Edit mode"
– clique sur "copy to mods folder"

– Exporter les fichiers ".awc" → "export to openFormats (.oac)".

3. Créer un nouvel audio / Remplacer l'audio existant

Le document "openFormats" exporté se compose d'un dossier contenant un ou plusieurs fichiers ".wav" et un fichier ".oac" correspondant.

– Téléchargez ou créez un nouveau audio (free sounds, générateur de voix IA, des enregistrements sonores, etc.)
– Ouvrez le fichier audio ".wav" original (par exemple avec Audacity)
– Modifiez le nouveau audio afin qu'il ait les mêmes paramètres que l'original
(réglez-le sur la même longueur, fréquence d'échantillonnage : généralement 44100 Hz, important ! Mono (1 canal) et 16 bits de profondeur, volume : -12 dB à -6 dB).
– Exportez-le sous forme de fichier ".wav"


Dans le document exporté, remplacez les fichiers ".wav" existants dans le dossier par les nouveaux (attention: certains fichiers ".oac" contiennent plusieurs audios, remplacez-les tous)
important! utilisez les noms existants

Après avoir remplacé les fichiers ".wav", faites glisser le fichier ".oac" correspondant vers le dossier OpenIV/ allez dans "Nouveau" dans le coin gauche > "Import openFormats" > choisissez votre fichier ".oac" > open > sélectionnez à nouveau votre fichier ".oac" dans la fenêtre qui apparaît* > ok > il est remplacé🙂

*→ Si le format est incorrect, une erreur apparaît et vous devez modifier à nouveau les paramètres correspondants

4. Jouer GTA avec l'audio remplacé

Ouvrez le jeu et trouvez l'audio que vous avez remplacé:
– Exemple audio des armes modifiées: ouvrez la section "Armes" dans GTA et recherchez l'arme portant le même nom.

– En cas de difficulté pour trouver l'objet modifié, installez un "Simple Trainer" pour vous aider.
(voir les instructions "Installation Simple Trainer")
