Comment installer l'extension Sollumz sur Blender

Ce tutoriel vous présente comment installer l'extension Sollumz sur Blender. Cette extension vous permettra de modifier les fichiers 3D de GTA (.xml, .yft).

Préparation

  1. Télécharger et installer Blender https://www.blender.org/download/

Sollumz

Sollumz est un addons Blender open source (sous licence GNU) dévellopé par Skylumz, Colton Fox et alexguirre. https://github.com/Sollumz/Sollumz. Cette addons vas nous permettre d'ouvrir et d'exporter des modèles 3D au format propriétaire utilisé par GTA V. Vous avez deux options pour installer Sollumz !

Option 1 :

Si vous n'avez pas de Get extension, vous pouvez directement passer à l'option 2 🪄

  1. Allez dans Edit > Preference > Get extensions > Repositories > + (add extension repository) > Add remote repository

  1. Copiez le lien https://repo.sollumz.org/ dans URL (trouvable sur https://docs.sollumz.org/getting-started/installation puis cliquer sur Create

  1. Cliquez sur Allow online Access

4.Cherchez Sollumz dans la barre de recherche des extensions et installer le Sollumz et Sollumz development (pas Sollumz RDR development)

5.Allez dans Add-ons et vérifier que Sollumz soit bien coché.

Option 2 :

  1. Téléchargez le fichier zip de Sollumz sur le site suivant site suivant IMPORTANT ⚠️: Ne pas déziper de dossier !!

  1. Allez dans Edit > Preference > Add-ons > install

  2. Cherchez le fichier zip Sollumz et cliquer sur Install Add-on

  1. Cherchez Sollumz dans la barre de recherche et vérifier que l'extension est bien cochée. Si ce n'est pas le cas, cocher la case et redémarrer blender
