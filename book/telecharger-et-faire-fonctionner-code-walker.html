Dans ce tutoriel, nous allons voire comment installer CodeWalker.

CodeWalker est un outil qui permet de parcourir, analyser et modifier le monde du jeu en 3D. Il propose une carte interactive en temps réel, avec des fonctionnalités telles que :

  • Exploration 3D de la carte du jeu
  • Chargement et édition des fichiers de map (YMAP, YBN, YDR, etc.)
  • Création et modification de scènes, d’objets et de scripts
  • Analyse des collisions, entités, routes, chemins pédestres
  • Visualisation des données du jeu (occlusion, zones, volumes, etc.)

Télécharger Code Walker

  • Téléchargez le fichier zip contenant Code walker par ici ←

  • Extraire le dossier zip “1cfcd8-CodeWalker30_dev46”

Dans le fichier il y aura plusieur .exe, lancez CodeWalker RPF Explorer.exe

La première fois que vous lancerez le logiciel, il vous demandera de sélectionner le chemin des fichiers du jeu. Si vous avez déjà installé Open IV, le logicel pourra détecter automatiquement le dossier du jeu

Une fois cette étape passée, le logiciel devrait prendre un temps pour charger toutes les données

Depuis code walker, vous pourrez ensuite exporter les fichier (notamment les .ytf) en .xml, ils seront ensuite importable sur blender.
