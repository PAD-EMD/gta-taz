Un tutoriel qui permet de télécharger et faire fonctionner code walker ce qui permettra d’extraire et d’exporter des fichiers GTA V à partir d’Open IV afin de pourvoir les importer dans d'autres logiciels (blender notamment), de les modifier et puis de les ré-exporter afin de les réinjecter dans le jeu.

---

Télécharger Code Walker

  • Téléchargez le fichier zip contenant Code walker par ici ←

  • Extraire le fichier zip 📁 “1cfcd8-CodeWalker30_dev46”

Dans le fichier il y aura plusieur .exe → lancez “CodeWalker RPF Explorer.exe”

La première fois que vous lancerez le logiciel, il vous demandera de sélectionner le chemin des fichiers du jeu : ( si vous avez déjà installé Open IV, le logicel pourra détecter automatiquement le dossier du jeu. )

  • Une fois cette étape passée, le logiciel devrait prendre un temps pour charger toutes les données, il faut patienter, attendre 🕰️⌛​ …

Depuis code walker, vous pourrez ensuite exporter les fichier (notamment les .ytf) en .xml ensuite importable sur blender 🐵
