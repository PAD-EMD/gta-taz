Prérequis

  • Installer Sollumz, lien du github pour le téléchargement: ici

Créer un objet dans blender

Ouvrir Blender (4.0?)
Supprimer le cube. Supprimer les objet existant dans la scène (a+x)

  • Créer un nouvel objet, par exemple un cube. (il faut un objet simple avec peu de vertex) - Installez “Sollumz”
    Vous n’avez pas besoin de de dézipper le fichier
    Dans Blender, aller dans Edit > preferences > install > add on et installer le fichier zip de “Sollumz” depuis votre disque.

  • Vérifier que l'échelle de votre objet soit à 1 (pour cela: object mode >object > apply> scale)
  • Aller dans “Sollumz Tools”
    Dans “Drawables”
    “create drawable objects” > “convert to drawable model”> “convert to drawable” (cela créer un empty pour votre objet)

  • Dans “Shader tools”
    Choisir material default > create shader material
  • Dans Edit > preference > activer “Node wrangler”
  • Ouvrir un onglet shader editor
    Dans la partie “Diffusesampler” ajouter l’image de votre texture en fichier .dds
    Cliquez sur l'icône dossier “open image” > aller chercher votre image.dds

  • Aller dans “Properties” puis dans l’onglet “Material”
    Défiler jusqu’à Sollumz > “Texture parameters” > cocher “embeded”
  • Dupliquer l’objet “.model”
    Ensuite faites > clic droit> “parent”> “clear and keep transformation”
    Renommer l’objet dupliqué en “ _collision” exemple (Cube_collision)
  • Dans “Sollumz tools” > “Collisions”> “Create bounds” > cliquez sur “Convert to composite” (cela crée une empty)

  • Retirer le matériaux de votre objet “collision” (exemple cube_collison.polymesh)
  • Dans “Sollumz Tools”
    Dans “Collisions” > “Create Collision Material” > prendre par exemple “Vfx metal electrified” > puis “Create Collision Material”

  • Pour le fichier “_collision.bvh” > dans object > “property object” > vérifier que le “sollumz type” soit “bound geometry bvh”

  • Dans “composite flag” décocher “map cover”

  • Pour le “_collision.polymesh” > dans object > “property object”> vérifier que le “sollumz type” soit “bound polymesh”

  • Dans collision Faire “select hiérarchie”
    Puis faire maj drag dans la collection de l’objet

  • Bien vérifier la hiérarchie
    Cube
    > Cube_model
    > Cube_collison

  • Dupliquer le fichier “.model”
    Le renommer en ajouter .med au bout (exemple cube_model.med)

  • Sélectionner le fichier .med > aller “drawable”> “lod tools”
    “Reference mesh” > prendre le fichier .med comme modèle
    Sélectionner med ou medium
    Cliquez sur “generate lods”

  • Supprimer le fichier med

  • Renommer la collection en par exemple “test_cube”

  • Sélectionnez le fichier .model

  • Allez dans sollumz tools

  • Allez dans archetype définition > YTYPS > create YTYP (+)
    Renommer le fichier (exemple test_sollumz_cube)
    Sélectionnez le empty

  • Dans archetype
    Vérifiez le type soit bien en “base”
    Puis cliquez sur auto Create archetype

  • Vérifiez les nomenclatures et le linked object
    Vérifiez que ce soit le même nom que l’empty
  • Export ytyp.xml
  • Exporter le ydr:
  • Sélectionnez toute la hiérarchie
  • Dans file > export > codewalker

  • Cochez “limit to selected object”

  • Cochez “apply parent transform”

  • Toggles lods > “high very low”
