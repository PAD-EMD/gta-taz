Insérer un fichier ydr dans une map Codewalker

02 octobre 2025, Millois Juan, Berthon Lou,HSU Ming Yuan

Un tutoriel qui permet d'importer un fichier ydr dans codewalker Il permettra d'importer un objet .ydr dans une map de Codewalker.

---

Télécharger Codewalker

  • Téléchargez le fichier zip contenant Code walker par ici
  • Téléchargez le fichier Open IV ici

Sélectionner un fichier ydr dans open IV ou Codewalker Explorer.

Ouvrir openIV
  • Sélectionnez un fichier ydr dans les dossiers «x64» depuis open IV ou depuis Codewalker Explorer
    Pour plus de facilité plus tard, sélectionnez dans un premier temps, un objet reconnaissable et évitez de choisir des bâtiments ou des morceaux de map.
    (Exemple d'objets: une tasse, un fauteuil, une télévision…)
  • Copier le nom du fichier, clic droit «copy name»

image1

Ouvrir codewalker

  • Dépliez le panneau à droite.
  • Cochez «Enable mods» et «Enable DLC».
  • Cochez Show toolbar en bas du panneau.

  • Choisissez un endroit reconnaissable.
  • Avant de créer un objet, il faut créer une map «.Ymap», (qui servira de scène dans laquelle on pourra insérer les objets).
  • Aller dans le premier icône de toolbar «new», puis sélectionnez «New Ymap File»
  • Un panneau va apparaître.
    En cliquant sur l’onglet «map1.ymap» vous pouvez modifier le nom par défaut de «map1».
  • Pour créer un objet, il faut cliquer sur le menu Ymap puis sélectionnez «new entity».
    Un œuf (objet par déafaut) va apparaître.

[

  • Au niveau de «archetype», remplacer le nom de l’objet par celui que vous avez copié précédemment dans open IV.
  • Supprimez le «.ydr» du nom copié
    Normalement votre objet va remplacer l’oeuf

![][

  • Vous pouvez maintenant bouger ou agrandir l’objet comme vous le voulez en utilisant les outils.

  • Si vous souhaitez placer un nouvel objet il faut à nouveau ajouter un «new entity»
