Tuto : changer les textes affichés dans GTA V (exemple : le nom de l'application "Snapmatic", mais fonctionne avec tous les textes (dialogues, menus, policies, etc))

1) Préparations / règles de sécurité (lire AVANT de commencer)

  • Toujours travailler dans le dossier mods/ d’OpenIV (ne pas modifier les fichiers « vanilla » du jeu).
  • Important : Ferme GTA V avant toute opération (sinon ça plante).
  • Précaution en plus : lance OpenIV en administrateur (clic droit → Exécuter en tant qu’administrateur).
  • Sauvegarde le .gxt2 original : clic droit → Export (ou Export to folder, ou faire un glisser/déposer) vers un dossier de backup.
  • Pas obligatoire mais, si possible, fais une copie du dossier mods\update\update.rpf\... entier avant de toucher quoi que ce soit.

2) Localiser le fichier .gxt2 à modifier

Dans OpenIV, navigue vers (ex. français) :

mods\update\update.rpf\x64\data\lang\french_rel.rpf\

Repère le fichier global.gxt2 (ou celui qui contient le texte à modifier).

3) Exporter en openFormats

  • Clic droit sur global.gxt2 → "Export to openFormats".
  • Choisis un dossier de travail (ex. D:\GTA_textes\global_gxt2_oxt\).
  • Résultat : OpenIV crée un fichier texte/export (.oxt / dossier openFormats) éditable.

4) Ouvrir / préparer le fichier pour l’édition

  • Ouvre le fichier exporté (.oxt) avec Notepad++, Bloc-notes ou VS Code.
  • Mets l’encodage sur UTF-8 without BOM.
  • Active l’affichage des retours à la ligne Windows (CRLF) si besoin.
  • Fais une copie de sauvegarde avant modification.

5) Rechercher et modifier la chaîne

  • Dans Notepad++ : Ctrl+F → recherche la chaîne (ex. "Snapmatic").
  • Exemple : APP_SNAPMATIC = Snapmatic → change en APP_SNAPMATIC = Snapchat.
  • Ne modifie pas la clé technique (avant le "=").
  • Sauvegarde ton fichier .oxt modifié.

6) Réimporter dans OpenIV (.oxt → .gxt2)

  • Méthode A : Glisser/déposer le fichier .oxt dans OpenIV en "Edit Mode".
  • Méthode B : Menu "File" → "Import openFormats" → sélectionne ton .oxt.
  • OpenIV le reconvertit automatiquement en .gxt2. Clique sur "Save" si nécessaire.

7) Tester en jeu

  • Ferme OpenIV et lance GTA V (solo).
  • Vérifie que le texte modifié apparaît bien (ex. "Snapchat" à la place de "Snapmatic").
  • Redémarre complètement le jeu si le texte ne se met pas à jour.

8) Pièges courants et solutions

  • Erreur d’import : vérifie que tu modifies le bon fichier french_rel.rpf.
  • Texte non affiché : la mauvaise clé a peut-être été changée.
  • Fichier corrompu : n’efface pas de lignes, garde la structure intacte.
  • Problèmes d’accents : assure-toi d’être en UTF-8 sans BOM.
  • Alternative : utilise VPC GXT2 Editor si tu préfères une interface graphique.

Et voilà ! Tu peux désormais modifier n’importe quel texte du jeu : menus, dialogues, crédits, noms d’objets, etc.
