Rockstar Editor

9 octobrer 2025

Julika Hother, Eda Tinmaz, Julien Cuisiat, Rufaro Mabuto

Rockstar Editor est un moyen d'enregistrer et d'éditer des clips directement dans GTA V. C'est une fonctionnalitée intégrée directement dans GTA. Ce tutoriel explique comment s'en servir.

  1. en jeu, en appuyant sur F1 (ou A + ↓ / X + ↓) - lancer le recording du gameplay. Le recording du gameplay continue automatiquement de record tant qu’il n’a pas été manuellement désactivé. Pour finir une sauvegarde de clip, le joueur doit être immobile. le recording du gameplay est très approximative (suivant la taille des clips)



  1. Le Rockstar Editor est accessible depuis les menus du jeu. (tout a droite)


3. Création de projet

CREATE NEW PROJECT : Pour lancer la table de montage et la modification de la capture in game dans un nouveau projet

LOAD PROJECT : Pour charger un projet existant

Les autres fonctionnalités servent au visionnage des clips, à trouver de la ressource sur le site Rockstar games et pour quitter.


4. Table de montage

Add clip : pour ajouter un clip à la table de montage

Add ambient Track / Add Radio Track : pour ajouter du son ou de la musique

Add text : ajouter du texte à l'écran

Les autres fonctionnalités sont similaires à n'importe quel autre logiciel (exporter, save as, …)


5. Editer ses clips

Lorsqu’on sélectionne “edit”, l’éditeur de gameplay s’ouvre, on revoit la séquence de jeu dans laquelle on peut modifier la caméra, le son, la vitesse, mettre des effects, changer la focale, préparer des transitions,… Chaque onglet ouvre un menu

Pour avoir une caméra très modulable il faut la régler sur “free camera”. On peut régler différents paramètres sur la caméra pour avoir de la précision. dès lors on est plus obligé de se balader autour du personnage.

6.Ajouter des marqueurs

il y a la possibilité d'ajouter des marqueurs qui permettent de créer des transitions dans le clip.

Il est intéressant de noter que toutes les touches de commandes sont toujours explicitées en bas de l'écran quelque soit le menu. Aussi si l'éditeur de clip est très intéressant, la table de montage est très limitée.
