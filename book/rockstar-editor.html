Rockstar Editor

Rockstar Editor est un moyen d'enregistrer et d'éditer des clips directement dans GTA V. C'est une fonctionnalitée intégrée directement dans le jeu lui même, officiellement. Ce tutoriel explique comment s'en servir et ses fonctionnalités de bases.

  1. En jeu, en appuyant sur F1 (ou A + ↓ / X + ↓), vous lancez le mode recording. À partir de ce moment, tout ce qui se passe dans la scène est enregistré jusqu’à ce que le mode recording soit interrompu.
    Pour finaliser et sauvegarder un clip, le joueur doit rester immobile pendant quelques instants.
    Le recording du gameplay reste cependant assez approximatif (en fonction de la taille des clips) : cela signifie que certaines actions ou animations peuvent ne pas être fidèlement reproduites lors de la lecture du clip.

  2. Le Rockstar Editor est accessible depuis les menus du jeu, tout a droite.

Création de projet

Une fois le Rockstart Editor chargé, vous allez avoir accés à plusieurs optioins:

  1. CREATE NEW PROJECT Pour lancer la table de montage et la modification de la capture in game dans un nouveau projet
  2. LOAD PROJECT Pour charger un projet existant

Les autres fonctionnalités servent au visionnage des clips, à trouver de la ressource sur le site Rockstar games et pour quitter.

Table de montage

À l'interieur de la table de montage vous allez pouvoir :

  1. Add clip pour ajouter un clip à la table de montage
  2. Add ambient Track / Add Radio Track pour ajouter du son ou de la musique
  3. Add text ajouter du texte à l'écran

Les autres fonctionnalités sont similaires à n'importe quel autre logiciel (exporter, save as, …)

Editer ses clips

Lorsqu’on sélectionne edit, l’éditeur de gameplay s’ouvre, on revoit la séquence de jeu dans laquelle on peut modifier la caméra, le son, la vitesse, mettre des effects, changer la focale, préparer des transitions etc. Chaque onglet ouvre un menu.

Pour avoir une caméra très modulable il faut la régler sur free camera. On peut régler différents paramètres sur la caméra pour avoir de la précision. dès lors on est plus obligé de se balader autour du personnage.

Vous avez la possibilité d'ajouter des marqueurs qui permettent de créer des transitions dans le clip.

Il est intéressant de noter que toutes les touches de commande sont toujours affichées en bas de l'écran, quel que soit le menu. Aussi, si l'éditeur de clips est très intéressant, la table de montage reste cependant très limitée.

Export

Une fois votre séquence satisfaisante, vous avez la possibilité d’exporter un fichier vidéo. Une fois exporté, le fichier vidéo se trouve à l’emplacement suivant : C:\Users\{votre nom d'utilisateur}\AppData\Local\Rockstar Games\GTA V\videos

⚠️ Attention : si vous lancez le jeu en mode administrateur, l’utilisateur actif sera forcément celui avec les droits administrateur sous Windows.

Il est important de noter que cet outil prend en compte les modifications externes apportées au jeu. Si vous avez créé ou importé des mods, ils seront visibles dans le Rockstar Editor.
