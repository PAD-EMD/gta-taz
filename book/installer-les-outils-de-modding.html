Pré-requis : installé GTA V sur un PC, et avoir accès au dossier contenant les différents éléments du jeu (qui va se trouver à un endroit différent de votre disque en fonction de si vous êtes passés par un launcher comme Epic Games, Steam ou Rockstar, ou si vous avez directement téléchargé le jeu (par exemple une version crackée).

Pour pouvoir installer et modifier des mods sur GTA V pour PC, tu auras besoin de :

OpenIV

→ pour explorer les fichiers du jeu et extraire/modifier les textures, modèles et fichiers .ytd / .gfx. Télécharger et installer openIV via le lien suivant (cliquer sur “Download now” puis ouvrir le fichier d’installation téléchargé, suivre les instructions étape par étape et attendre la fin de l’installation) → https://openiv.com/.

Ouvrir openIV, sélectionner “GTA V” et bien choisir la version “Windows”, puis indiquer le chemin du dossier dans lequel se trouve le fichier d’application “GTA5” (le dossier contenant les éléments du jeu) .

Ouvrir Open IV

Activer le “Mode Édition” en haut à droite

Créer un backup des fichiers originaux dans OpenIV : Tools → ASI Manager → Installer “ASI Loader” et “OpenIV.ASI” → Close (pour ne modifier que des copies des fichiers originaux du jeu et ainsi pouvoir récupérer ces derniers s’il y a un problème)

Dans explorateur de fichers

Script Hook V a mettre dans la racine permet d'exécuter des scripts personnalisés dans GTA V.
→ Lien pour le téléchargement
Télécharger le dossier à partir du lien, puis ouvrir l’archive
Se rendre dans le sous-dossier “bin” puis sélectionner le fichier “dinput8.dll” et le drag&drop dans la racine du dossier du jeu.

Une fenêtre windows s’ouvre et propose de remplacer le fichier “dinput8.dll” car il existe déjà dans la racine → cliquer sur “Remplacer le fichier dans la destination” ou “Oui”

Sélectionner ensuite le fichier “ScriptHookV.dll” et le glisser également dans la racine du dossier du jeu

Script Hook V .NET (a mettre dans la racine)→ te permet d’écrire des scripts en C# (.NET)
→Lien pour le téléchargement


⚠️⚠️⚠️INSTALER LE “NIGHTLY BUILDS” ⚠️⚠️⚠️

Télécharger le dossier à partir du lien, puis ouvrir l’archive (bien prendre la version “ScriptHookVDotNet-v3.6.0-nightly.126”)

Une fois dans le dossier, sélectionner les 7 fichiers dont le nom commence par “ScriptHookVDotNet” (exclure les dossiers “Docs” et “Licenses” ainsi que le fichier texte “README”) et les glisser dans la racine du dossier du jeu

Installation du Trainer (logiciel ou script externe qui sert de menu de triche et de gestion : il permet d’accéder instantanément, en temps réel, à des options normalement impossibles ou limitées dans le jeu (argent illimité, armes, véhicules, météo, téléportation, activation de mods, etc)
Ouvrir le lien suivant, cliquer sur “Télécharger” une première fois, ce qui va ouvrir une autre page, puis une deuxième fois sur cette autre page pour lancer le téléchargement
→ Lien pour le téléchargement

une fois le dossier compressé téléchargé, l’ouvrir et sélectionner les deux derniers fichiers (nommés “TrainerV.asi” et “trainerv.ini”) puis glisser ces derniers dans la racine du dossier du jeu

Ce tutoriel est à présent terminé ! Vous disposez désormais de tous les éléments de base nécessaires à l’installation de la plupart des mods pour GTA V, et votre jeu est correctement configuré. Lorsque vous désirerez installer un mod à l’avenir, prenez bien le temps de consulter la description de celui-ci sur la plateforme sur laquelle vous le trouvez (par exemple GTA5-Mods.com) ou le fichier texte “readme” contenu dans son dossier, s’il y en a un. En effet, certains nécessitent la présence d’autres fichiers ou applications mais pas de panique, vous trouverez presque tout le temps les instructions nécessaires à l’installation de votre mod, et il n’y aura normalement pas de manipulations trop complexes. Merci d’avoir suivi ce guide jusqu’au bout :)
