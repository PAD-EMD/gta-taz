Tuto : modifier un .ytd dans GTA V (exemple : loadingscreen_startup.ytd)

06/10/2025, Jolaine KANDA, Ameni HAJJI, Yohan schmitt, Léo BONO

1) Préparer l’environnement

  • Télécharge et installe OpenIV (si ce n’est pas déjà fait).
  • Assure-toi que ton dossier mods est bien configuré dans OpenIV (ASI Manager → “Install OpenIV.ASI” et “Enable mods folder”).
  • Active "Edit Mode" en haut à droite de la fenêtre OpenIV.

2) Localiser le fichier .ytd que tu veux

  • Dans OpenIV, navigue vers : mods\update\update.rpf\x64\data\cdimages\scaleform_generic.rpf\
  • Trouve le fichier loadingscreen_startup.ytd (bien vérifier qu'on est dans le dossier mods).

3) Exporter les textures en PNG

  • Double-clique sur loadingscreen_startup.ytd → Le Texture Viewer s’ouvre : il affiche toutes les textures contenues.
  • Sélectionne une ou plusieurs textures (par ex. beach_bg ou beach_fg).
  • Clique sur “Export all textures” ou “Export Selected” → “Export as PNG” et choisis un dossier (ex. D:\GTA_V\textures\).
  • Répète pour chaque texture que tu veux modifier.

4) Modifier les images

  • Ouvre les PNG exportés dans Photoshop (ou GIMP, Paint.NET…).
  • Modifie-les selon tes besoins (changer un logo, ajouter une image, etc.).
  • Attention : ne change pas les dimensions de l’image, garde exactement la même résolution.
  • Sauvegarde en PNG 24 bits ou 32 bits (si tu veux garder la transparence).
  • Les noms des fichiers doivent rester identiques aux originaux (ex. beach_bg.png).

5) Réinjecter les textures modifiées dans le .ytd

Méthode rapide (Replace)

  • Retourne dans OpenIV → rouvre loadingscreen_startup.ytd.
  • Clique sur “Replace”.
  • Sélectionne ton PNG modifié → OpenIV remplacera la texture à l’intérieur du .ytd.
  • Sauvegarde en cliquant sur “Save”.

Méthode avancée (nouveau .ytd)

  • Dans OpenIV : Tools > Texture Dictionary > New.
  • Nom : loadingscreen_startup.ytd.
  • Clique sur “Add” → importe tous tes PNG modifiés.
  • Sauvegarde avec “Save”.
  • Dans scaleform_generic.rpf, clic droit sur le .ytd → “Replace” → choisis ton nouveau fichier.

6) Tester en jeu

  • Lance GTA V (solo).
  • Regarde l’écran de chargement → la première image devrait apparaître modifiée !

7) Astuces & précautions

  • Fais toujours un backup du fichier original avant remplacement.
  • Teste d’abord avec une seule texture modifiée.
  • Respecte toujours les dimensions et formats des PNG d’origine.
  • Si l’écran reste noir ou bug → restaure l’original et vérifie les dimensions.

Et voilà ! Avec cette méthode, tu peux modifier n’importe quel .ytd du jeu : pas seulement les écrans de chargement, mais aussi les icônes du téléphone, les textures de véhicules, d’armes, de vêtements, etc.
