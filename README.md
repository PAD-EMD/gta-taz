# GTA TAZ
Documentation en ligne du programme de recherche Édition média design de l'ÉSAD Orléans sur le modding du jeu GTA V.

# Installation
`npm install`
`npm run dev`

# Objectifs du projet
Dans le cadre du mois de la recherche, le PAD explore la pratique du mod qui consiste à transformer un jeu vidéo existant pour en modifier la narration, les mécanismes ou le sens. En partant du jeu Grand Theft Auto (GTA), créé en 1997 par David Jones et Mike Dailly, nous verrons comment cette pratique permet de révéler les principes narratifs et vidéoludiques de ce médium et questionnerons l’intégration de nouvelles formes de créativités artificielles dans le processus de création et les formes d’agentivités propres au jeu vidéo.

# Organisation
À partir du travail de wireframe réalisé par les étudiant.e.s, l'équipe de dev du projet à pour tâche de construire le site. Celui-ci accueille des tutoriels pour modder le jeu GTA V ainsi que des articles. Le principe de navigation du site se base sur l'interface des radios dans le jeu.
