Ce tutoriel a pour objectif de vous montrer comment installer l'extension Sollumz sur Blender. Cette extension vous permettra de modifier les fichiers 3D de GTA (.xml, .yft)

Télécharger Blender

La première étape est de télcharger blender : https://www.blender.org/download/

Installer Sollumz

Vous avez deux options pour installer Sollumz !

Option 1 :

Si vous n'avez pas de Get extension, vous pouvez directement passer à l'option 2

1. Aller dans Edit - Preference - Get extensions - Repositories - "+"(add extension repository) - Add remote repository

2. Copier le lien suivant dans “URL” 🧷: https://repo.sollumz.org/ (trouvable sur https://docs.sollumz.org/getting-started/installation) puis cliquer sur “Create”

3. Cliquer sur "Allow online Access"

4. Chercher “Sollumz” dans la barre de recherche des extensions et installer le “Sollumz” et “Sollumz development” (pas “Sollumz RDR development”)

5. Aller dans "Add-ons" et vérifier que Sollumz est bien coché ✅

Option 2 :

1. Télécharger le fichier zip de Sollumz sur le site suivant IMPORTANT ⚠️: Ne pas déziper de dossier !!

2. Aller dans Edit - Preference - Add-ons - install

3. Chercher le fichier zip Sollumz et cliquer sur "Install Add-on"

4. Chercher Sollumz dans la barre de recherche et vérifier que l'extension est bien cochée. Si ce n'est pas le cas, cocher la case et redémarrer blender
